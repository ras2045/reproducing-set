What this book actually is

The fine-structure constant, assembled from parts

A formula built from a small set of framework constants reproduces CODATA's value for 1/α to an error of 8.836806×10−10. That precision is real and exactly computed. Whether it means anything is a different question — answered here by an exhaustive search of every reduced fraction with the same denominator range, which turned up four simpler fractions fitting the same target at least as well:

FractionErrorvs. the claimed fraction
7/4319.79×10−119× closer
9/5543.75×10−10closer
12/7394.52×10−10closer
11/6776.75×10−10closer

A dedicated verifier — now on its eighth revision, each version closing a hole found in the previous version's own checking logic — also computes the power of the "only one combination matches" argument used to defend this claim: a random target in the same range gets hit by some combination about 2% of the time, and of those hits, 100% are hit by exactly one. The verdict stands: FAILED. Do not treat the alpha claim as verified — not because the arithmetic is wrong, but because precision alone was never sufficient evidence.

A falsifiable prediction that failed cleanly

A separate rule predicted a specific dip in prime-gap statistics at one shell (231 = 21×11) and nowhere else across a tested range of seven. Real, previously computed data existed to check it:

3 of 7 correct — worse than chance — and the one shell the whole rule was built to confirm came back wrong. A clean, unambiguous falsification, and the best kind of result a sharp prediction can produce.
