Quant Tools

Where this came from

Six independent, rigorous tests asked whether this project's prime/alphabet encoding reveals real structure in a real model's activations (allenai/OLMo-2-0425-1B). All six came back null — an order confound, a real bug in the analysis code, a proper permutation power test, a dictionary chi-square check, a personal-text check. Every one is on the record as a null result, not quietly dropped.

What survived the same session was unrelated to that hypothesis entirely: the project's existing 31-level quantization codebook, originally built to test data compression, turned out to be a genuinely good way to quantize real neural network weights — a completely different, much more mundane use of the same fixed codebook. That part got verified properly and is what this plugin ships.

What it actually does

Block size 32, one fp32 scale per block, every weight assigned to its nearest of 31 fixed codebook levels — a real quantization pass over a real .safetensors file, not an estimate from metadata.

1Reads the safetensors header directly (plain JSON) — no torch, no safetensors package.
2Quantizes each 2D weight tensor, chunked by row to bound memory on large embedding/lm_head matrices.
3Reports the real compression ratio and per-tensor cosine fidelity — near-zero/dead rows excluded from the fidelity stat, since cosine is numerically unstable there and those rows contribute ~0 downstream anyway.

Verified, twice

The full-model result (all 179 tensors of a real 1.48B-parameter model): 5.05:1 compression, 0.997058 mean cosine fidelity, and a real generation test confirmed the fully-quantized model still produced coherent output. When this plugin was packaged, it was re-run independently against a fresh slice of the same real cached model weights — the result matched the original almost exactly: 0.997051 cosine fidelity.

Run it

/plugin marketplace add ras2045/p18-tools-marketplace
/plugin install quant-tools@p18-marketplace

/quant-tools:quant-analyze /path/to/model.safetensors

Only reads local files — never uploads or downloads model weights.
